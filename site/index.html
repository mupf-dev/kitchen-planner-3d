Installation

One Node process, one SQLite file. Or try the live demo first.

git clone https://github.com/mupf-dev/kitchen-planner-3d.git
cd kitchen-planner-3d
docker compose up -d --build
# → http://localhost:3010
# requires Node.js ≥ 22.18
git clone https://github.com/mupf-dev/kitchen-planner-3d.git
cd kitchen-planner-3d
npm install
npm run build && npm start
# → http://localhost:3001
npm install
npm run dev     # Vite :5173 + API server :3001
npm run build   # type check and build into dist/
Behind HTTPS, set TRUST_PROXY=1 and COOKIE_SECURE=1. Data lives in DATA_DIR (Docker: /data).
  1. First accountTop right “Log in” → “Sign up”. The first account becomes the administrator.
  2. Control sign-upsIn user management, turn sign-up on or off and approve new accounts.
  3. Graphics cardFor fast path tracing, switch your browser to the dedicated GPU – the planner shows you how.

Guide

The key steps at a glance. The interface is available in English and German.

1 · Create the room

Tab Room: enter dimensions and click Create walls – or draw walls and place doors and windows.

2 · Trace a floor plan

Upload an image, calibrate it with Scale using a known distance and trace the walls.

3 · Place cabinets

Tab Catalog: pick an element, click into the floor plan. R rotates, Alt places freely.

4 · Choose surfaces

Tab Materials: one material per area, or upload your own colour or texture.

5 · Photorealistic

Switch to 3D at the top, then Photorealistic. The image refines over time – save it with Image.

6 · Share

Log in, save the plan and create a showroom link – or export it as JSON.
